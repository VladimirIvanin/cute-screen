# Тени снимка: исследование и решение

2026-10-20. Запрос: выразительная многослойная тень, независимое увеличение
размера и компактные понятные controls.

## Источники

- [Figma: Apply effects to layers](https://help.figma.com/hc/en-us/articles/360041488473-Apply-effects-to-layers):
  Blur смягчает границу, Spread расширяет силуэт, X/Y задают смещение;
  цвет и opacity регулируются отдельно. Это разные операции, их нельзя
  заменить одним процентом силы.
- [Figma: Shadow spread](https://www.figma.com/blog/behind-the-feature-shadow-spread/):
  spread меняет геометрию источника тени; у rounded rect вместе с размерами
  изменяется радиус. Это позволяет сделать тень шире без чрезмерного размытия.
- [Fluent 2: Elevation](https://fluent2.microsoft.design/elevation/):
  направленный key-слой отделяет край от поверхности, ambient-слой даёт мягкую
  глубину. Большая мягкая тень воспринимается как большая высота.
- [Josh W. Comeau: Designing Beautiful Shadows](https://www.joshwcomeau.com/css/designing-shadows/)
  и [Tobias Ahlin: Layered smooth shadows](https://tobiasahlin.com/blog/layered-smooth-box-shadows/):
  сочетание разных blur/offset/alpha даёт более плавный профиль. Свет должен
  иметь согласованное направление; большое число слоёв увеличивает стоимость.
- [MDN: shadowBlur](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/shadowBlur):
  Canvas shadow blur не масштабируется текущей матрицей. Плотность offscreen
  маски учитывается явно; CanvasKit использует sigma = blur / 2 с respectCTM.

## Применение к Cute Screen

Рекомендация по результатам исследования — два уровня управления. Сразу видны
пресеты, плотность и размер. Расширенные параметры открываются по необходимости.
Уровень отдельных слоёв пока не нужен: он добавил бы три набора одинаковых
полей и противоречил бы запросу на компактность. Три слоя рассчитываются вместе.

| Настройка  | Диапазон      | Что меняется                                            |
| ---------- | ------------- | ------------------------------------------------------- |
| Плотность  | 0–100%        | Alpha всех слоёв; 0 полностью выключает тень            |
| Размер     | 25–400%       | Масштаб blur, автоматических offset и внутренних spread |
| Мягкость   | 10–200%       | Только blur; размер/плотность не сбрасываются           |
| Расширение | −128…256 px   | Дополнительное сжатие/расширение силуэта                |
| Сдвиг X/Y  | −1024…1024 px | Смещение относительно автоматического направления       |
| Цвет       | RGB           | Общий оттенок трёх слоёв; плотность остаётся отдельной  |

Размер — относительный масштаб рецепта; px — координаты экспортируемой карточки,
не экранные CSS px. Базовая единица пропорциональна короткой стороне снимка:
clamp(0.1, min(width,height)/800, 8). Поэтому рисунок не исчезает при fit 4K/8K.
Слои: контактный (blur 2u, Y 0.8u, alpha 0.32), направленный (12u, 4u,
spread −u, alpha 0.28), рассеянный (40u, 14u, spread −3u, alpha 0.24).
Alpha умножается на плотность; size и softness изменяют геометрию отдельно.
Это собственный рецепт проекта, а не копия токенов указанных систем.

Нулевые поля или фиксированный холст могут обрезать большую тень по границе
экспорта. UI подсказывает увеличить поля: размер холста автоматически не меняется.
Большой blur не обязан делать тень темнее; для широкой плотной тени нужны
размер и положительное расширение, затем плотность по вкусу.

## Проверяемые ограничения

Тень привязана к внешнему контуру снимка/рамки и исключена внутри него, включая
прозрачные пиксели. Canvas2D использует native blur и cache трёх непрозрачных
масок с отдельной alpha-композицией. Максимальная сторона маски 2048 px;
три маски и результат занимают не более 64 MiB на renderer для этого рецепта.
Изменение плотности переиспользует маски; resize заменяет cache, dispose
освобождает surfaces. CanvasKit использует MaskFilter, а не CPU pixel readback.
4K/8K software perf на общем Windows host — только trend evidence, не GPU SLA.
